# Windows 安装、切换与恢复

1. 将源码 ZIP 解压到英文路径。安装 Git for Windows、uv、Node.js 24 LTS 和可用的 Windows Python 3.12。准备微信桌面端。运行 `Start-WhaleMaiNext.cmd` 会在缺少环境时执行 `Setup.ps1`，按提交和 SHA-256 下载上游源码，并安装两套固定版本的 Python 依赖。
2. 在桌面应用点「启动麦麦」和「麦麦 WebUI」。按麦麦的界面完成首次配置，并填写自己的聊天、视觉和 embedding 模型。使用本实例创建的 Bot。点「全部停止」，在桌面点「安装适配器」。只有一个已初始化 Bot 时可留空目录名。
3. 再启动麦麦，在 WebUI 启动选定的 Bot。确认适配器已启用及拥有 manifest 列出的能力。桌面「已配对」指插件已通过本机认证开始轮询。
4. 保存微信账号的准确目录名和允许的会话 ID。每套安装固定一个账号。图片模式 `request` 需同一发言人在同一会话发送 `/识图` 后 60 秒内发图，`auto` 接收普通图片，`off` 关闭图片。输出图片时把会话保持在准确的前台窗口。
5. **切换前退出旧微信桥接并确认它已停止监听。** 不要把旧项目数据、聊天或 Key 搬入新端。本版需要由合法来源单独提供、与该账号对应的数据库凭据文件 `WhaleGirl/data/wechat-cache/<账号目录名>/keys.json`。没有该凭据时停在麦麦或离线验证阶段。凭据存在且微信公开了可用 UIA 后，再点「连接微信」。首次真机收发应由操作者选定会话和消息内容。

端口分别为 19787（本机队列）、19788（远程网页）、19789（微信内核）及 19790（麦麦 WebUI）。47821 沿用跨安装微信桥接互斥锁。手机访问需自行为 **19788** 配置 HTTPS 中转，并在桌面显式开启远程控制。关闭远程开关即停用远程 API，外部中转由其配置者停止。Key 只在本机生成，认证时通过请求头传输。

可选语音需要 .NET 10 Desktop Runtime 及用户自行安装的 VB-CABLE。使用 .NET SDK 10.0.404 运行 `Build-VoiceWorker.ps1`，在本机生成 `WhaleMaiVoiceWorker.exe`。在「语音设置」填写厂商、HTTPS API 基址、Key、模型、音色和虚拟声卡播放端点 ID。Key 使用当前 Windows 用户的 DPAPI 保存。「检查麦克风」仅核验设备，「切换麦克风」更改 Windows 默认录音和通信设备。微信的语音快捷键须与应用配置一致。结束后可在 Windows 声音设置中切回原设备。

更新前完全停止此应用，私下备份本实例的 `data/`、`instance/`、`WhaleGirl/config.json` 与 `WhaleGirl/data/`。覆盖前核对发布版本与存储格式。恢复旧服务时，先断开新端并确认已退出，再使用原快捷方式启动旧服务。本机停止或取消队列无法撤回已发消息。
