# 数据处理

白名单会话中的消息、图片、会话标识以及本账号观察到的文字进入本机队列。麦麦消费这些内容，并按用户选择将相关请求交给聊天、视觉或 embedding 服务。仅在语音授权生效后，语音回答文本会交给所选 TTS 服务。其响应音频用于本机虚拟声卡，正常执行结束时删除临时音频。

本地队列、会话记录、帐号凭据、诊断文件分别保存在 `data/`、`instance/` 和 `WhaleGirl/data/`。远程控制向认证过的浏览器提供授权会话及发送操作。自行设置 HTTPS 中转时，网页流量也会经该中转。请将微信数据库凭据、远程控制 Key、模型 Key 和整个运行目录视为私密数据。

反馈故障时提供版本、退出码和合成复现步骤。完全停止后才清理本地数据。删除本地文件不能撤回已经由微信发送、由浏览器接收或由模型服务处理的内容。
